## План реализации ссылки на обратный конец кабеля 

### Определение обратного конца кабеля
Определить у выбранного клемника, для которого строится отчет, 20006 ОУ (полное). Пример =HII-1.1++ЯЧ67+#1-X2
Определить подключенные к клемнику кабели. Механика уже есть в коде.
Определить у каждого кабеля подключенного к клемнику свойства: Кабели: источник <20376> и Кабели: цель <20377>. Они будут вида: =HII-1.1++ЯЧ67+#1-X2, =HII-1.1++М+#1-SB1
Обратный конец это свойство отличное от 20006 ОУ (полное) клемника. В приведенных примерах =HII-1.1++М+#1-SB1 есть обратный конец.

### Вставка нового символа (точка разрыва)
Необходимо выполнить вставку нового символа (аналогично вставке символа кабеля). Библиотеа SPECIAL символ 8 / BP (точка разрыва) (вариант А(0) для горизонтального расположения отчета, вариант H(7) для вертикального.
Символ должен вставляться на конце линии после символа кабеля. К символу применить отображение порядок свойств из point/, формат xml
Если обратный конец кабеля клемник, то есть ОУ начинается на Х (англ или рус). Варианты ХТ, Х, XT, X, XTA то порядок свойств брать из ТР_Кабель(горизонт).emc - для горизонтального расположения отчета, ТР_Кабель(вертик).emc для вертикального  

Если обратный конец кабеля устройство, то есть ОУ не подходит под определение клемника.  То порядок свойств брать из ТР_Устройство(горизонт).emc - для горизонтального расположения отчета, ТР_Устройство(вертик).emc для вертикального  

Существующую стрелку на конце линии убрать. Символ точки разрыва представляет собой стрелку, поэтому дополнительная графика не нужна

### Присвоение ОУ точке разрыва
Если обратный конец кабеля клемник, то присвоить полное ОУ точки разрыва такое же как у клемника обратного конца, кроме буквенного кода. Буквенный код присвоить такой же как у кабеля на линию которого ставится точка разрыва с добавлением суфикса (EXT).
Пример: 
определенный обратный конец кабеля: =HII-1.1++ЯЧ17+#1-X2
кабель: =HII-1.1++М+#2-K190
ОУ точки разрыва: =HII-1.1++ЯЧ17+#1-K190(EXT)

Если обратный конец кабеля устройство, то присвоить полное ОУ точки разрыва такое же как у устройства обратного конца.
Пример: 
определенный обратный конец кабеля: =HII-1.1++М+#1-SB1
кабель: =HII-1.1++М+#2-K100
ОУ точки разрыва: =HII-1.1++М+#1-SB1

### Для кабелей подключенных к нескольким клемникам
Для кабелей подключенных к нескольким клемникам вставить символ точки разрыва. Библиотеа SPECIAL символ 8 / BP (точка разрыва) (вариант G(6) для горизонтального расположения отчета, вариант F(5) для вертикального.
Символ должен вставлятся на обратный конец шины (к которой идут соединения от клемника). Противоположный где вставлен символ кабеля.
К символу применить отображение порядок свойств из point/, формат xml 
Для горизонтального клемника - ТР_кабель(int_горизонт).emc
Для вертикального клемника - ТР_кабель(int_вертик).emc
